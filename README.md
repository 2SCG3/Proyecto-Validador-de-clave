# Proyecto Final Algoritmos: Validador de contraseña 

Este proyecto tiene como fin educar al usuario en las mejores prácticas para la creación de contraseñas seguras.
Además, incluye recomendaciones para fortalecer la protección y el manejo responsable de credenciales. 

El programa permite al usuario crear contraseñas seguras basado en requisitos de ciberseguridad y buenas practicas de ambientes de desarrollo reales. También crea y sugiere contraseñas seguras para ayudar al usario.

Git Bash → ./run.sh
Linux → ./run.sh
macOS → ./run.sh
Windows CMD → run.bat

## Instrucciones de Uso:
1. Lee las instrucciones para crear una contraseña segura. 
2. Crea una contraseña que cumpla con los requisitos de seguridad, o permite al programa generar una automaticamente. 
3. Lee las recomendaciones de seguridad para fortalecer la protección y el manejo de contraseñas. 

## Requisitos para crear una contraseña segura 

1. La contraseña debe tener al menos 8 caracteres. Nivel de seguridad: débil.
2. Letra mayúscula
3. Número
4. Carácter especial (. , o *)

#### Recomendaciones de seguridad: 

1. No reutilices contraseñas en diferentes sitios web.
2. Considera usar un gestor de contraseñas para almacenar y generar contraseñas seguras.
3. Cambia tus contraseñas regularmente y especialmente si sospechas que han sido comprometidas
