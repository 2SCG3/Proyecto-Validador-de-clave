# Proyecto Algoritmos

A small Java project for learning and implementing algorithms.

## Project Structure

```
src/
├── main/
│   └── java/        # Main source code
└── test/
    └── java/        # Test code
```

## Building the Project

### Using Maven
```bash
mvn clean compile
```

### Running the Project
```bash
mvn exec:java -Dexec.mainClass="Main"
```

### Running Tests
```bash
mvn test
```

## Requirements

- Java 11 or higher
- Maven 3.6 or higher

## Getting Started

1. Add your Java classes to `src/main/java/`
2. Add your test classes to `src/test/java/`
3. Build and run using Maven commands above
